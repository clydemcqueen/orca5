# SLAM Control

## Setup

* Copy [script_buttons.lua](script_buttons.lua) to `~/colcon_ws/scripts`.
* Enable scripting and map `BTN0_SFUNCTION`..`BTN3_SFUNCTION` to 108..111, see the [ArduSub parameters](../orca_gz/config/sim.parm)

## Operation

* Press shift-B on the Xbox controller (script button 2) to enable SLAM.
* Press shift-X on the Xbox controller (script button 3) to disable SLAM (and reset the SLAM map).
